# Pelea de Barrio 🥊

Juego de peleas en el navegador con 13 luchadores, 3 escenarios y remates finales ("¡DALE EL REMATE!").

## Cómo jugar
Descarga `index.html` y ábrelo en cualquier navegador (Chrome, Safari, Edge, Firefox). No necesita internet ni instalación.

## Controles
| Acción | Jugador 1 | Jugador 2 |
|---|---|---|
| Moverse | A / D | ← / → |
| Saltar | W | ↑ |
| Bloquear | S | ↓ |
| Puño | F | K |
| Patada | G | L |
| Especial / Remate | H | Ñ |

En celular aparecen botones en pantalla (modo 1 jugador vs CPU).

## Reglas
- Gana quien se lleve 2 de 3 rounds (99 segundos cada uno).
- Pegar llena la barra azul; con la mitad llena puedes lanzar el especial.
- En el K.O. final aparece **¡DALE EL REMATE!**: tienes 5 segundos para pulsar el especial y hacer el remate de tu personaje.
